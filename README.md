# sparseSOMNiBUS_simu

This repository contains the simulation code for the manuscript:  
**“A novel high-dimensional model for identifying regional DNA methylation QTLs.”**

## 📁 Folder Structure

- **`ToLoad/` and `ToLoadFast/`** — Core R functions used in all simulation runs.
- **`Experiment-smooth/Scripts/run_100snps_samp_50.R`** — Example script for running the smooth-effect simulation with 100 SNPs and sample size 50.

## 🔧 Usage

To replicate a simulation scenario, load the relevant functions from `ToLoad` or `ToLoadFast`, then execute the script under the corresponding `Experiment-*/Scripts/` directory.
